# 保険特化LP（公務員向け） — 設計仕様

- 日付: 2026-05-22
- 事業: Life Village（TechVillage）
- 関連: [2026-05-01 LP刷新（v2）](./2026-05-01-life-village-renewal-design.md)

## 1. 目的

既存の Life Village LP（v2：総合マネー相談）に並列して、**保険に特化したLP**を新設する。
ターゲット層を「公務員でありながら、よくわからずに何かしらの保険に入ってしまっている層」に絞り込み、
保険観点での無料診断・無料相談 CV を獲得する。

## 2. ターゲット

- 公務員全般（教員・地方公務員・国家公務員・みなし公務員）
- 加入経緯が「窓口で勧められた／職場斡旋／親世代の紹介」で、契約内容を自分で説明できない層
- 20〜50代、特に結婚・出産・住宅購入などライフイベント前後で見直し意欲がある層

## 3. メイン訴求軸

**「その保険、本当に公務員のあなたに合っていますか?」**

- 公務員共済（高額療養費付加給付・遺族共済年金・互助会給付）と民間保険の**重複加入**を最大ペインとして据える
- 「保険を売る」ではなく「いまの保険を整理する」スタンス（中立性の演出）

## 4. スコープ

カバーする保険領域は**生命・医療・がん**に絞る（人を起点とする保険）。
自動車・火災等の損害保険は本LPでは扱わない（既存総合LPの守備範囲）。

## 5. CTA 戦略

| 種別 | 配置 | 遷移先 |
|------|------|--------|
| 主CTA | Hero / 中間 / FAQ後 | 既存「総合マネー診断」 `https://life-diagnosis.vercel.app/diagnosis` |
| 副CTA | Hero / 最終CTA セクション | LINE 相談（既存v2と同じ `https://lin.ee/XTFxWwZ`） |

診断は既存アプリを流用する（保険観点での再設計はしない）。
診断結果ページから保険相談への導線を強化する施策は別タスクで検討。

## 6. ファイル配置

```
TechVillage/life-village/lp/
├── v2/               # 既存：総合マネー相談LP
│   ├── index.html
│   └── style.css
└── insurance/        # 新設：保険特化LP
    └── index.html    # CSSは既存v2と同様にインライン化
```

公開URLは別途設定（例: `https://life.tech-village.co.jp/insurance/`）。
本タスクではホスティング設定は対象外。

## 7. ページ構成

既存v2の7ブロック構成（Hero → 課題提起 → サービス概要 → 公務員特化の理由 → 相談の流れ → FAQ → 最終CTA）を踏襲。
セクションIDとクラス名は流用し、中身のコピー・データのみ差し替える。

### ① Hero
- メインコピー: 「その保険、"なんとなく"で<br>続けていませんか？」
- サブ: 公務員専門の保険セカンドオピニオン窓口
- CTA: 主「無料診断する」/ 副「保険相談する」

### ② 課題提起：公務員のあるある加入経緯
3カードで提示：
1. 窓口で勧められるまま契約した
2. 職場で斡旋された保険にそのまま入った
3. 親世代に勧められて言われるまま契約した

### ③ 3つの落とし穴（既存「サービス概要」枠を転用）
1. **共済との重複**：高額療養費付加給付があるのに医療保険に厚く入っている
2. **死亡保障の過剰**：遺族共済年金で十分なのに高額な終身保険に入っている
3. **不要特約**：先進医療・通院特約など使わない特約に毎月支払っている

### ④ 公務員共済 vs 民間保険（既存「公務員特化の理由」枠を転用）
比較表を中心に、以下を見える化：
- 高額療養費制度（自己負担上限）＋ 付加給付（共済の上乗せ）
- 遺族共済年金（公務員家族への給付）
- 互助会・福利厚生からの給付金

「だから民間保険は"最低限"でいい」というメッセージで締める。

### ⑤ 相談の流れ
既存v2の4ステップ構造を流用：
1. 無料診断（5問）
2. 結果に応じて専門家とマッチング
3. オンラインで無料相談（30〜45分）
4. 必要に応じて見直し提案／継続OKの判断もあり

文言だけ「保険」文脈に微調整する。

### ⑥ FAQ（保険特化で再構成）
- Q. しつこい営業はありますか？
- Q. 共済と民間保険、結局どちらに入ればいいですか？
- Q. いま入っている保険を解約する必要がありますか？
- Q. オンラインだけで完結しますか？
- Q. 相談は本当に無料ですか？収益源は？

### ⑦ 最終CTA
- 主CTA = 無料診断
- 副CTA = 無料相談
- メッセージ:「保険は"入る"より、"整える"時代へ。」

## 8. デザイン方針

- カラーパレット・タイポ・グラスカード・余白は既存v2と同一
- CSS は v2 の `<style>` ブロックをそのまま使用（インライン）
- セクションラベル英字（例: `INSURANCE` / `PITFALL` / `BENEFIT`）のみ差し替え
- 画像／イラストは v2 で使っているものがあれば流用、なければ絵文字＋テキストで代替（既存LPと同じ流儀）

## 9. SEO / メタ情報

- `<title>`: 「公務員のための保険セカンドオピニオン窓口 | Life Village」
- `<meta description>`: 「公務員共済と民間保険の重複を整理。Life Village の保険セカンドオピニオンで、本当に必要な保障を無料診断。」
- OGP は既存v2の構造を流用、画像・タイトル・description を保険版に差し替え

## 10. 非スコープ

以下は本タスクでは扱わない：

- 診断アプリ（`/diagnosis`）の保険観点への改修
- 公開ホスティング設定（Cloudflare Pages / Vercel ルーティング）
- A/Bテストハーネス
- 既存v2 LPの修正
- 自動車・火災保険トピック

## 11. 完了条件

- `lp/insurance/index.html` が単体ブラウザで開いて崩れず表示される
- 全てのCTAボタンが既存v2と同じ遷移先（診断URL / LINE）に正しく繋がる
- レスポンシブ（スマホ・タブレット・PC）で破綻しない（v2と同条件）
- メタ情報・OGPが保険LP向けに差し替わっている
